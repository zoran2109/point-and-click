# Point and click adventure investigation

This repository is used as a playground during investigation on how to create old-school (2D) point and click adventure.

I expect to:
1. use chosen engine (Godot) and library (Popochiu) to make sample game (MOST IMPORTANT)
2. document useful information on game development (SECONDARY and OPTIONAL, along the way)

## Why
I'm not a gamer and I'm not a game developer. But I always liked the old-school adventure games. Those adventures had good stories, stimulating (OK, sometimes frustrating) puzzles, they didn't try to steal my life away with excessive duration and, on top of that, they had low hardware requirements. Also, for quite a while I have a desire to create a game as a side project. Although I eventually went into web development, my first step towards this career was in a way connected with game development. First book that I read was _Python Programming for absolute beginner_ by Michael Dawson. The learning material in the book was structured around making simple games and it was fun! I guess that this project is a chance to get back to this feeling - and to create a simple game - although it probably won't be heavy on coding.

## Goals
I won't reinvent the wheel here for the sake of learning to build 2D engine or framework/library on top of it that offers some point and click functionality. I'm making this constraint with the aim of actually creating something tangible.

Sample game:
1. create two scenes/rooms (so the character can travel between the two)
2. add one dialog
3. add interactive objects
4. add one puzzle (simple) whose solving ends the game
5. add sprites and background (from existing templates)
6. add music

Investigation ideas:
1. engine choices and libraries/frameworks for point and click game development
2. roadmap for creating the game
3. sources for pixel-art templates, game assets
